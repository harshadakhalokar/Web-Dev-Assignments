# Web Development Assignments

This repository contains my **Web Development assignments and practical implementations** created as part of my academic coursework.

The repository will include different assignments covering fundamental and intermediate concepts of web development, including **HTML, CSS, JavaScript, XML, AJAX, and related web technologies**.

The assignments may cover topics such as:

* HTML and semantic web pages
* CSS styling and layouts
* Forms and form validation
* JavaScript programming
* DOM manipulation and interactive web pages
* JSON and AJAX
* XML and DTD/XML Schema
* E-commerce web pages
* Interactive applications
* Other web development practicals

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

* **JSON**

* Other web technologies as required by the assignments

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/harshadakhalokar/Web-Dev-Assignments.git
```

2. Open the required assignment folder.

3. Open the `.html` file in a web browser.

For assignments using JavaScript, JSON, AJAX, or multiple files, it is recommended to run them using **VS Code with Live Server** or another local development server when required.
